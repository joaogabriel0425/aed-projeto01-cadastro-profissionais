# Projeto 01 - Cadastro de Profissionais com Arvore Binaria de Busca

Trabalho da disciplina de Algoritmos e Estruturas de Dados.

Sistema de cadastro de profissionais de saude.
Em memoria, os registros ficam em uma arvore binaria de busca.
Em disco, ficam no arquivo profissionais.csv.
Todos os dados sao ficticios.
## Funcionalidades
- Cadastrar profissional
- Buscar profissional pela matricula
- Listar todos em ordem crescente de matricula
- Exibir a arvore com recuo por nivel
- Remover profissional
- Contar profissionais
- Sair 
## Arquivos
- cadastro_profissionais.c
- profissionais.csv
